# Assistant Platform Knowledge Bundle

Durable knowledge about the three distributions in this repository, in
[Open Knowledge Format](https://github.com/GoogleCloudPlatform/knowledge-catalog/blob/main/okf/SPEC.md)
v0.2. Plain markdown with YAML frontmatter and no tooling: if you can `cat` a
file you can read it.

This is not a replacement for `README.md` (what the packages are and how they
are gated) or for code comments (why one line is the way it is). It holds what
neither can: the choices that had a real alternative, and what is still
outstanding.
